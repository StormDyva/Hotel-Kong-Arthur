# Specify

## Status

Draft – udfyldes og godkendes af gruppen.

## Formål

At give Hotel Kong Arthur et system, der kan registrere bookingdata og analysere hotel- og cocktailbarens drift.

## Brugere

- Receptionist: håndterer bookinger.
- Hoteladministrator: analyserer drift og indtjening.
- Beslutningstager: bruger Tableau-dashboardet.

## Funktioner

- Booking CRUD
- Analyse af belægning og indtjening
- Analyse af gæster efter land
- Analyse af cocktailbarens salg
- Tableau-dashboard
- OpenAPI/Swagger
